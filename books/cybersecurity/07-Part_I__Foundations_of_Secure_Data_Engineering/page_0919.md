Outputting Data to Elasticsearch  
 By default, Logstash sends data stream traffic to a stream called  logs-generic-default  in Elasticsearch. This data stream unfortunately doesn’t automatically exist. To add it, create the following API request in Kibana’s Dev Tools, after the previous API request, then press  CTRL - ENTER  to send it to Elasticsearch: 
  PUT /_data_stream/logs-generic-default
