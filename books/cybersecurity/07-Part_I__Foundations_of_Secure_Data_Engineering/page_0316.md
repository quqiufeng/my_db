Configuration  
 We’ll configure and test Winlogbeat before copying it to a location accessible only to administrators, where making changes would be tedious. Copy the primary configuration file,  winlogbeat.yml , to a backup copy named  winlogbeat.yml.original  so you can restore it if needed. Then, open  winlogbeat.yml  using your editor of choice and replace its contents with the following: 
  winlogbeat.event_logs:
 ❶  - name: Application
   ❷  ignore_older: 72h
  - name: System
  - name: Security
  - name: Microsoft-Windows-Sysmon/Operational
  - name: Windows PowerShell
   ❸  event_id: 400, 403, 600, 800
  - name: Microsoft-Windows-PowerShell/Operational
    event_id: 4103, 4104, 4105, 4106
