Summary  
 Apache Kafka is a powerful tool for moving data across the enterprise. It creates one central location to which your organization can send streaming data and allows multiple consumers to access the data simultaneously. Tools you’ve used previously, such as Rsyslog and Logstash, integrate seamlessly as producers, consumers, or both at the same time. 
 In this chapter, you created your own Kafka cluster. You used TLS connections to send and receive data from the cluster management tools included with Kafka. You also used Rsyslog, Filebeat, and Logstash to send Kafka real events and receive events in return. Finally, you stored your Kafka configurations using Git. 
 Next, we’ll cover Ansible, an automation tool for deploying software, updates, or system changes across multiple servers at once.
