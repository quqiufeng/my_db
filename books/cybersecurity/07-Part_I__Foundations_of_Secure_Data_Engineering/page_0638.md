After updating your DNS server or  /etc/hosts , add firewall rules to allow TCP ports 22, 9093, and 9094. Your Kafka nodes will use port 9093/TCP for interbroker communications and 9094/TCP for incoming client connections. Port 22/TCP is for Secure Shell. Run the following command on systems that use UFW: 
  $  sudo ufw allow 22,9093,9094/tcp
