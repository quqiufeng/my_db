SAVING CONFIGURATIONS WITH GIT  
  In your local Git repository, create a new directory for your filters if you didn’t already, then copy your configurations and additional notes there, and redact any credentials. Track the new files with   git add .   and then commit them by running   git -a -m   &lt;message&gt;  . Finally, run   git push   to add them to your remote repository.
