Creating Users and Directories  
 Let’s create a dedicated user to run Kafka, appropriately named  kafka . On each virtual machine, add the  kafka  user and set their password to  abcd1234 ; on RHEL, substitute  wheel  for  sudo : 
  $  sudo useradd -s /bin/bash -d /home/kafka -m -G sudo kafka 
$  sudo passwd kafka
