SAVING CONFIGURATIONS WITH GIT  
  If you’re not already working out of a Git repository, copy your Ansible directory to your local repository. Modify or create a new   .gitignore   file as well to prevent pushing your vault to the remote repository, if desired. Track new changes with   git add .  , then commit your changes with   git commit -am "added Ansible files"  . Finally, use   git push   to send the changes to your remote repository. As you work from your local repository and add new tasks you find useful, remember to push them to the remote repository.
