YAML  
 YAML is a recursive acronym of the phrase “YAML Ain’t Markup Language.” In this book, we’ll use YAML to create and edit configuration files, not to transmit or receive data. You’ll create many YAML configurations from scratch, so it’s worth familiarizing yourself with the format. 
 YAML also uses key-value pairs, but it relies on whitespace and indentation rather than JSON’s quotations and brackets to communicate relationships between data fields.
