SAVING CONFIGURATIONS WITH GIT  
  If you aren’t already working from a Git repository, add your working files to one, redact any credentials, and track the files with   git add .  , then check them with   git status  . Commit changes using   git commit -am   &lt;message&gt;  , then use   git push   to send your notes and files to your remote repository.
