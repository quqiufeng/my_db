Windows File Transfer and Shell Access Tools  
 If you’re using a Windows computer to host the Linux virtual machines, you should consider installing a couple of additional tools to make file transfers and shell access easier. The first is WinSCP, used for moving files between Windows and your virtual machines, available at   https://  winscp  .net  /eng  /download  .php  . The second tool, PuTTY, is an SSH client that you can use to access your virtual machines’ command line interface from a Windows host, without using each virtual machine’s user interface. PuTTY is available at   https://  www  .chiark  .greenend  .org  .uk  /~sgtatham  /putty  /latest  .html  . Note that Windows has an SSH client built in, but it lacks many features that make PuTTY worthwhile.
