Executing Commands  
 At first glance, Ansible’s  command  and  shell  modules appear to do the same thing: run commands on remote systems. The modules have a minor difference, however;  shell  loads a new shell session, which lets commands pipe values to each other, whereas  command  uses Python’s  subprocess  module to spawn processes directly and doesn’t support piping. 
 The following command uses the  command  module to list the contents of the remote user’s home directory, the default directory Ansible connects to when accessing a remote host. Note the presence of the  CopyMe.txt  file, which you just distributed using the  copy  module: 
  $  ansible all -i inventory.yml -m command -a "ls -lh"
