Adding Directional Tags  
 In the previous section, we tagged network events to indicate whether they were inbound or outbound by using  if - else  statements to control code processing. Let’s take the configuration one step further by adding a new field to hold this direction information. It’s often worth creating such a field because otherwise, your Kibana query to find outbound traffic might look like this: 
  tags:source_homenet AND NOT tags:destination_homenet
