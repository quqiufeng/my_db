Installation  
 Begin by installing the base Rsyslog package, the documentation, and the OpenSSL and Kafka add-ons. If you’re on Ubuntu or Debian, run the following command: 
  $  sudo apt install rsyslog rsyslog-doc rsyslog-openssl rsyslog-kafka
