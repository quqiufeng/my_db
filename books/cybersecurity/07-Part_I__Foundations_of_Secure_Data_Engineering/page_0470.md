Notice that we set the connection options in the  input  statement, not in the  module  statement. This is because the input statement is the portion that reaches out to Kafka, similarly to how the  imtcp  input initiates a listening port. 
 This code reads from a topic named  syslog  and connects to three brokers, starting with  kafka01 . The array in square brackets contains the multiple broker names, although you may also specify a single name in quotes like other strings. Kafka uses the  consumergroup  to track which messages have been sent to which recipients, per grouping. The  parsehostname  option allows Rsyslog to read the hostname from the received message for further processing, although this option is set to  off  by default.
