Setting the Branch’s Remote Origin  
 If you try to push your code to the remote repository, however, you’ll get an error, as you haven’t set the remote-origin version of the  dev  branch: 
  $  git push 
The current branch dev has no upstream branch.
To push the current branch and set the remote as upstream, use
    git push --set-upstream origin dev
