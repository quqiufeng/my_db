Intermediate Signing  
 To receive a signed intermediate certificate, we need a certificate signing request and a SHA-512 key pair. Run the following command to generate the intermediate CA’s certificate signing request, named  ca-int.csr , as well as the key pair: 
  $  openssl req -config ~/tls/configs/openssl-intermediateca.cnf -new -keyout 
 ~/tls/caintermediate/ca-int.key.pem -out 
 ~/tls/caintermediate/ca-int.csr -outform PEM -passout pass:abcd1234
