Output Modules  
 Outputs define locations to which to send data, whether writing it to a file or using a network protocol. Most of the input modules have output companions, but Rsyslog supports slightly more output varieties than it does inputs. Two of the most common outputs,  omfile  for writing to files and  omfwd  for sending data to another tool, don’t need to be loaded. 
 By default, Rsyslog creates files with  0644  permissions for the user running Rsyslog, typically  root . This access mode lets anyone read logs located   in directories to which they have access. The easiest way to use this module is to give it a full filepath: 
  action(type="omfile" file="/var/log/myapp.log")
