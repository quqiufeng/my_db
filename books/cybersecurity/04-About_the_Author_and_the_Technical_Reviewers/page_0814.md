Modifying hosts Files  
 We’ve previously used the  /etc/hosts  file to record hostname resolution information for IP addresses. Generally, it’s best to use a DNS server instead of relying on keeping each server’s  /etc/hosts  files in sync. If you don’t have a DNS server, however, you can use Ansible to enforce configurations based on inventory files and variables. First, add the domain  .local  to  vars/vars.yml  so the task can reference it: 
  domain: .local
