Exploring Available Event Logs  
 Winlogbeat can read any source in the event log, adding flexibility to your logging strategy and collection requirements. This includes third-party antivirus event logs, Dynamic Host Configuration Protocol (DHCP) events, Server Message Block (SMB) client activity, and more. Let’s examine additional event logs Winlogbeat can read. 
   Use the following two PowerShell commands to view all available log sources and all log sources with more than zero events, sorted by size: 
  PS&gt;  Get-WinEvent -ListLog * 
 --snip-- 
PS&gt;  Get-WinEvent -ListLog * | where RecordCount -gt 0 | sort -descending -property RecordCount
