We now have the signed certificate,  rsyslog.local.flex.cert.pem . Rsyslog’s OpenSSL module regrettably can’t decrypt private keys that use passphrases, so let’s make a copy of the private key without it. Note that you can omit the  -passin  argument to be prompted for the passphrase on the command line: 
    $  openssl rsa -in ~/tls/keys/rsyslog.local.flex.key.pem -passin pass:abcd1234 
 -out   ~/tls/keys/rsyslog.local.flex.key.nopass.pem
