This chapter won’t include user access control lists (ACLs), which can further restrict how applications access Redis, but the following commands demonstrate how to add them in the form of users: 
  &gt;  acl setuser setonly on allkeys +set &gt;abcd1234 
&gt;  acl setuser getonly on allkeys +get &gt;abcd1234
