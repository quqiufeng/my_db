Firewall Ports  
 We need to open some firewall ports to allow Logstash traffic. Use the following commands for Ubuntu’s Uncomplicated Firewall (UFW): 
  $  sudo ufw allow 5044/tcp 
$  sudo ufw allow 5514/tcp
