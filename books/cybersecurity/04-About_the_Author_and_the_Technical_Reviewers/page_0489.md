Now that you have a working flex certificate, place the certificate and private key in  /etc/ssl , the system location for TLS files. Rsyslog runs as the  syslog  user, so we’ll make root own the TLS files and  syslog  able to read them. First, make the  rsyslog  directory inside  /etc/ssl . Next, set its permissions to  750  so that the directory can be entered by the root and  syslog  users (execute) and so that files can be listed (read): 
  $  sudo mkdir /etc/ssl/rsyslog 
$  sudo chmod 750 /etc/ssl/rsyslog
