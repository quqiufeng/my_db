Adding Container Files  
 To include all TLS files we’ve created throughout this book, let’s make PKCS#12 and Java KeyStore container files. First, let’s add some variables inside the inventory file, underneath the group name  kafka , which affect the remaining tasks in this section:

  children:
    kafka:
       vars: 
         requires_pkcs12: yes 
         requires_jks: yes 
      hosts:
        kafka01:
