Virtual environments contain a  symbolic link , or shortcut, to your system’s Python binaries, allowing the project to run “in a bubble” and act as a stand-alone environment. First, create a new directory using  virtualenv  to contain the packages you’ll need. Then, use the virtual environment’s Python package installer,  pip , to install the web server  Flask  and the OpenSSL wrapper  pyopenssl : 
  $  virtualenv myapp 
$  myapp/bin/pip install flask pyopenssl
