The  ExecStart  line uses  /bin/sh  to launch the  kafka-server-start.sh  helper tool. It will use the  server.properties  file you just made and redirect terminal output to  /data/kafka/kafka.log . The  ExecStop  line gracefully terminates the Kafka processes. Also note the commented  SyslogIdentifier  line, which lets you set a specific program name in syslog messages for this process. After adding the service file, run the following command so systemd identifies the new service file: 
  $  sudo systemctl daemon-reload
