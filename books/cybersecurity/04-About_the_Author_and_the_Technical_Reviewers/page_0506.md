This code loads the  ossl  stream driver, which uses OpenSSL. (Alternatively, you could load the  gtls  module to implement GnuTLS, which supports passwords applied to private keys.) We set the stream driver mode to  1  to force TLS usage and set the stream driver authentication mode to  x509/name  to enforce certificate validation checks and subject-name authentication. 
 The permitted peers setting is optional but lets you add specific servers to an allow list for additional control. You can specify either IP addresses or resolvable domain names. After loading and configuring the module, use the  input  statement to initialize the port.
