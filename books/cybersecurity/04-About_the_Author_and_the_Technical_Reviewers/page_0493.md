Basic vs. Advanced Formats  
 Rsyslog supports multiple configuration formats. Its  basic  format, commonly used by older systems, mirrors other logging programs and is popular because it uses a simple syntax for light tasks. 
 The basic format includes a selector comprising one or more combinations of logging facilities and priorities joined by a period, followed by a destination, such as a file or remote host: 
  kern.*    /var/adm/kernel
