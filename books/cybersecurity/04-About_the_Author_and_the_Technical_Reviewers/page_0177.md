The  branch  command shows an asterisk next to the active branch. Adding  -a  shows all remote branches: 
  $  git branch 
* dev
  main
$  git branch -a 
* dev
  main
  remotes/origin/HEAD -&gt; origin/main
  remotes/origin/main
