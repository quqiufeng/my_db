Verifying Connectivity  
 Now that you’ve created SSH keys and a configuration file, started the agent, and copied the public key to the remote servers, test the secure connection by entering the following command. Substitute the following IP address with the one you’re connecting to: 
  $  ssh 192.168.2.20
