We use the same bootstrap servers  ❶  to make the initial connection to Kafka. Instead of specifying a consumer group, we set a client ID  ❷ , used to identify a publisher during debugging. We specify the same TLS settings for the keystore and truststore. Logstash uses  topic_id   ❸  to specify the topic to send data to. The topic name in this example uses a printf-style variable that references a metadata field containing the name of the Beats data being processed. In this way, Logstash can route data to the appropriate topic based on the event being processed.
