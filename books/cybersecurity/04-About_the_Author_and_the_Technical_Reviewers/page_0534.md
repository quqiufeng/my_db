Example Configurations  
 We’ve discussed Rsyslog components and how they interact. Now let’s make two working configurations: a client that takes local host logs and sends them to Logstash and a central Rsyslog relay server that receives network logs, forwards them to Logstash, and simultaneously writes them to disk in   files named after the host from which the logs originated. In both cases, we’ll leave the default configurations  20-ufw.conf  and  50-default.conf  enabled.
