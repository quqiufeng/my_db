The Discover interface includes a search bar, a time picker, a drop-down menu for selecting various available datasets, and rows of individual events. The only logs coming into Elasticsearch should be system metrics and a handful of host events generated by your Elastic Agents. 
 To search for events in Kibana, use the syntax  field  :  value . For example, the search term  source.ip:192.168.8.130  would find events originating from the specified IP address. You can use parentheses, quotations,  OR , and  AND  statements to craft more complex queries, as in this example: 
  destination.domain:("fleet.local" OR "kibana.local") AND destination.ip:"192.168.8.0/24"
