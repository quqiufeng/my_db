Event Log Types  
 Windows has hundreds of event logs to support thousands of applications. These event logs could contain evidence of security issues, crash reports, hard drive performance data, CPU temperature warnings, and more. Windows stores the binary logfiles in  C:\Windows\System32\winevt\Logs . Let’s cover the most common logs by volume, as well as some uncommon ones that provide immense security value.
