The first command sends a request using basic authentication (username and password) to the Elasticsearch server, which responds with a JSON message stating simple information about the server. The second command calls an API for health status, which, among other details, shows the status as  green . The third command calls a different health API, and the filters in the URL path show only the JSON keys we’re interested in: the cluster name and status, which is also  green . These responses mean Elasticsearch installed successfully.
