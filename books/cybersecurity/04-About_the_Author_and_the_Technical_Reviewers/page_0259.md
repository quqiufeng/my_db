ECS uses  @timestamp  to label the time an event occurred, although additional time-related fields, such as  event.start  and  event.end , can provide more granular time information. 
 Notice a problem in this example: The  @timestamp  value  ❶  shows the time at which the logs were read by Filebeat, instead of the value in  processed.timestamp   ❷  representing the time of the actual event. The value is notably wrapped in quotes when displayed, as Filebeat treats it as a string object, not a date object. This is because we didn’t tell Filebeat to use  processed.timestamp . We’ll discuss modifying this behavior in the “ Processors ” section on  page  65  .

   ❸  - syslog:
