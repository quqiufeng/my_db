Within the  http_poller  input type, the  urls   ❶  statement allows us to nest multiple API queries. These APIs can have any names you want, so choose descriptive ones, such as  mytextapi   ❷  and  myjsonapi   ❺ . Each API configuration block contains the HTTP request method, the URL including the desired endpoint in the URL path  ❸ , and custom headers  ❹   ❻ . The  mytextapi  block connects to the plain-string endpoint we configured, and    myjsonapi  connects to the  /json/  endpoint. The schedule statement supports making connections based on cron intervals  ❼  and every syntax  ❽ , in addition to others. The every syntax in this configuration runs every five seconds, although you may use  5m  for five minutes,  1h  for every hour, or some other value. This input tracks requests sent and received, so we nest them in their own dedicated parent field,  http_poller_metadata   ❾ , to avoid any parsing conflicts later.
