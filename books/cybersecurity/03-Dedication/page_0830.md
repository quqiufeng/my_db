These functions create three API endpoints: one that returns a simulated API key, another that validates it, and a third that simulates sending an HTTP POST request to Kibana. Together, these functions mimic the process of requesting API keys from Elasticsearch and Kibana to configure a fleet server and then using the key to configure Elastic Agent. The  fleetapipage  function returns the JSON you send it, so you can visually check what the remote server receives. After you’ve added the functions, restart your web server by running the following command in the directory where it’s stored: 
  $  ./app.py
