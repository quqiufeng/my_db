If you absolutely insist on using an array to check a single value, you could add your single term to the array twice, though it’s better to just use a string or regular expression match in this case. 
 You also can’t compare an array field to an array. Assuming the  host.ip  field has the value  ["192.168.99.99", "fe80::1234:5678:1a:2bcd"] , the following snippet won’t work even though the field and the array contain the exact same values: 
  # Doesn't work
[host][ip] in ["192.168.99.99", "fe80::1234:5678:1a:2bcd"]
