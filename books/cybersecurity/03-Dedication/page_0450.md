SAVING CONFIGURATIONS WITH GIT  
  Copy any commands and configurations you’ve saved for Elasticsearch and other tools in this chapter into a new directory named   elastic   in your local Git repository, and redact any important credentials. Track the files using   git add .   and then run   git status   to ensure your new files are tracked. Commit the changes by running   git commit -am "added elastic files"  . Finally,   git push   them to your remote repository.
