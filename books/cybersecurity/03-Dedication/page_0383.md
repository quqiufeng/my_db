The Keystore File  
 Elasticsearch supports individual PEM key and certificate files, combined Java Keystore files, and PKCS#12 container files. For simplicity, let’s combine the private key and certificate into one PKCS#12 file: 
  $  openssl pkcs12 -export -inkey tls/keys/wildcard.local.flex.key.pem -in 
 tls/certs/wildcard.local.flex.cert.pem -passin pass:abcd1234 -out 
 tls/certs/wildcard.local.flex.pkcs12 -passout pass:abcd1234
