Ignoring Files  
 What if you don’t want Git to track a certain file at all? The  .gitignore  file is a list of files, directories, and wildcards that prevents Git from revealing your private files, such as sensitive configurations or private keys, to the whole world. 
 To practice using this feature, make a blank file named  sensitive.conf  in your project directory: 
  $  touch sensitive.conf
