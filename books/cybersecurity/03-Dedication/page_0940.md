Reading Threat Intelligence  
 The Filebeat instance running on the cyber threat intelligence server will periodically request threat intelligence indicators from a list of intelligence providers you’ll configure shortly. Begin by backing up the original  /etc/filebeat/filebeat.yml  file, then create a new one with the following contents: 
  output.logstash:
  enabled: true
  hosts: ["threatintel.local:5044"]
    ssl.enabled: true
  ssl.verification_mode: full
  ssl.certificate: /etc/ssl/bookproject/wildcard.local.flex.cert.pem
  ssl.key: /etc/ssl/bookproject/wildcard.local.flex.key.pem
  ssl.key_passphrase: abcd1234
  ssl.certificate_authorities:
    - /etc/ssl/bookproject/ca-chain.cert.pem
