Distributing Threat Intelligence with Memcached  
 In this section, you’ll use Memcached to once again send Filebeat data to Logstash on a cyber threat intelligence node. This time, however, Logstash will distribute the indicators to each data node instead of loading a leader database. The data nodes will be responsible for loading their own caches,   as Memcached doesn’t use replication. We’ll discuss strategies for preventing cache  drift , or differences between each data node’s cache values, at the end of this section.
