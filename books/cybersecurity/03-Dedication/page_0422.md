The Elastic Agents  
 To add an agent to your fleet, repeat the agent setup process on your first Elastic virtual machine host. Because you won’t configure this agent to be a fleet server, you can skip certain steps. Create a directory for TLS files and download them: 
  $  mkdir -p /opt/Elastic/Agent/certs/ 
$  cd /opt/Elastic/Agent/certs/ 
$  wget 192.168.8.133:8080/tls/certs/wildcard.local.flex.cert.pem 
$  wget 192.168.8.133:8080/tls/keys/wildcard.local.flex.key.nopass.pem 
$  wget 192.168.8.133:8080/tls/certs/ca-chain.cert.pem 
$  chmod 0640 *
