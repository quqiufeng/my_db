Please note that Logstash and Beats support using keystores as well. Elasticsearch is based on Java and includes the necessary self-contained code to run when you install it. As this isn’t a production deployment, let’s severely limit the Java Virtual Machine (JVM) heap size, where certain values are held in memory. These heap changes prevent Elasticsearch from consuming all available resources on your virtual machine. Create  /etc/elasticsearch/jvm.options.d/heap.options  and add the following lines: 
  $  nano /etc/elasticsearch/jvm.options.d/heap.options 
-Xms1g
-Xmx1g
