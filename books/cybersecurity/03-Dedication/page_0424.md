In a root terminal or using  sudo , run the following command to install the agent: 
  $  ./elastic-agent install \ 
   --force \ 
   --url=https://fleet.local:8220 \ 
   --enrollment-token=ZUVrVWt... \ 
   --elastic-agent-cert= 
 /opt/Elastic/Agent/certs/wildcard.local.flex.cert.pem \ 
   --elastic-agent-cert-key= 
 /opt/Elastic/Agent/certs/wildcard.local.flex.key.nopass.pem \ 
   --certificate-authorities=/opt/Elastic/Agent/certs/ca-chain.cert.pem
