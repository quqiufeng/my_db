Amazon S3 and MinIO  
  Amazon S3  is an object storage solution that is part of the Amazon Web Services (AWS) cloud. Logstash can connect to S3  buckets , which are conceptually like directories, to store files or read ones placed there by other programs. 
 S3 isn’t free; it’s priced based on the amount of data you store and the amount of data transferred to and from your buckets.  MinIO , a free object storage software alternative to S3, uses the same APIs for compatibility but lacks some of S3’s more niche features. Logstash can also use most of the same S3 input and output plug-ins to connect to MinIO. (We’ll look at certain capability gaps shortly.) Configuring S3 and MinIO is well beyond the scope of this book, but you can find extensive documentation and video tutorials on the internet. 
   The Logstash S3 input downloads files in a bucket to temporary files. You can download all files or just those specified with a prefix, such as  2040 . It then reads those temporary files to push their data through filters before sending them to the output plug-ins. This allows you to control which logs Logstash consumes and which it ignores. 
 The term  prefix  has additional meaning in AWS terminology that you can read about at   https://  repost  .aws  /knowledge  -center  /s3  -prefix  -nested  -folders  -difference  , but for the purposes of this section, it relates to the first characters in a filename when used in the S3 input or to a subdirectory when used in the S3 output.
