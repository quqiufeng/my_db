Kibana  
 In the root terminal on your first Elastic virtual machine, run the following commands to create a certificate directory for Kibana and download the TLS wildcard files: 
  $  mkdir -p /etc/kibana/certs 
$  cd /etc/kibana/certs 
$  wget 192.168.8.133:8080/tls/certs/wildcard.local.flex.pkcs12 
$  wget 192.168.8.133:8080/tls/certs/ca-chain.cert.pem 
$  chown -R root:kibana * 
$  chmod 0640 *
