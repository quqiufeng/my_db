Configuring DNS and Firewall Rules  
 Let’s add firewall rules so the services can communicate with each other. On systems that use Uncomplicated Firewall, add the following allow rules. Note that if you’ve already added the SSH port (22) rule, this command will skip over it: 
  $  sudo ufw allow 22,9200,5044,5601,8220,8221/tcp
