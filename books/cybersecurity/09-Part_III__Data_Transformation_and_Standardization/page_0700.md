By setting  LogAppendTime , we tell Kafka to calculate message retention based on how long it has held an individual message, regardless of the timestamp included in the event’s metadata. Otherwise, if Kafka were set to retain only seven days’ worth of data but you sent it data from logfiles   that were months or years old, Kafka would immediately drop them once received! We also allow topics to be deleted and disallow dynamic topic creation.
