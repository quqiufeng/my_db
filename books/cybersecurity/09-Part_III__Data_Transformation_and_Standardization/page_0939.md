The  set  command requires a 32-bit flag that Memcached will store along with the data, a TTL in seconds, and the bytes for the data to be stored. In the following command, let’s set the flag to  0 , as we don’t need to   store any application-specific bytes with each value. Set a new 4-byte value,  abcd , with a 30-second TTL: 
  # set VALUE FLAGS(INT) TTL(SECONDS,INT) BYTES(INT)
&gt;  set abcd 0 30 4 
&gt;  1234 
&gt; STORED
