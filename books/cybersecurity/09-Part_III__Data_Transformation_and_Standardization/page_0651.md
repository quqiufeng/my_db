Writing Filters with Ruby Scripting  
 Ruby is an object-oriented programming language that uses methods, control flow, variables, and other common features. You can write your own Ruby filters, either inline or in a separate script file, to further control the processing of your data, which is useful in cases when no other Logstash filter can efficiently do what you need.
