Conversely, you can check if a field’s value is part of a string, in another field, or in an array field: 
  # Checking whether a field is part of string
[user][name] in "JamesBonifield"
# Checking whether a field is part of another field
[user][name] in [source][user][name]
# Simulating some array field
[user][name] in ["JamesBonifield", "SomeOtherUser"]
