The  -F none  option tells Ansible not to load a configuration, and the  PreferredAuthentications  option tells it to log in using a password, if the remote system allows it. If you don’t want to make an entire SSH configuration file, the Ansible command line option  --ssh-common-args  lets you specify SSH options for ad hoc commands, which we’ll cover shortly: 
  $  ansible --ssh-common-args "-F none -o PreferredAuthentications=password"...
