Finally, let’s enable a Unix socket in addition to localhost. The Unix socket will allow programs on the same host to interact with Redis without the overhead of using the TCP network stack. Uncomment the  unixsocket  and  unixsocketperm  lines, and change the permissions to  0666  so that any program on the same host may reach Redis; be sure to reassess these permissions if you use Redis in production: 
  unixsocket /var/run/redis/redis-server.sock
unixsocketperm 0666
