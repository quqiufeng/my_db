On Red Hat Enterprise Linux, CentOS, and Rocky Linux, substitute  dnf  for  apt  and install  ansible-core , but note you won’t have access to community features. If you want to install Ansible using Python (this may be a better idea on RHEL), which also allows you to import its code in other scripts, use Python 3’s  pip  module: 
    $  python3 -m pip install --user ansible
