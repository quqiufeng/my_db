Tasks like querying APIs, running commands affecting a server cluster, or writing results to a file are good candidates for delegating tasks and running them one time. For example, consider creating Kafka topics, which you did in   Chapter 10  ; you needed to create topics only once, and trying to do so multiple times would have returned errors. In that case, you could pick just one of your Kafka nodes and then delegate the topic-creation commands.
