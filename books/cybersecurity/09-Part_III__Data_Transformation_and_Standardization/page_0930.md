You can set a time-to-live (TTL), or expiration value, using the  EX   &lt;number&gt;  option after providing the key you want to set. The following command gives  abcd  a lifespan of five seconds, after which Redis drops it from the cache: 
  &gt;  set abcd 1234 EX 5 
&gt;  get abcd 
"1234"
