Intermediate Configuration  
 We’ll use an intermediate CA, sometimes called a signing CA, to sign requests for tool-specific certificates. In production, intermediate CAs provide a buffer between the root CA and user certificates to limit the root CA’s exposure to leaks or destruction. To configure the intermediate CA, copy the root configuration into a new file named  openssl-intermediateca.cnf : 
  $  cp ~/tls/configs/openssl-rootca.cnf ~/tls/configs/openssl-intermediateca.cnf
