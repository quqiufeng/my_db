 Ansible is available via  apt  and  dnf  and as a package from the PyPi Python package repository. Two main versions of Ansible are available: plain Ansible and Ansible Core. Ansible includes built-in standard packages, such as those for copying files and adding users, but also highly rated community modules that do things like modify firewall rules or generate X.509 certificates. Ansible Core includes only the built-in modules. 
 On Ubuntu and Debian, use  apt  to install the full Ansible package:
