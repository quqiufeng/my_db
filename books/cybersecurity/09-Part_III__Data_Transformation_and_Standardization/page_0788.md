The  apt  module’s  name  argument supports wildcards. When used while changing  state  to  latest , these can direct Ansible to install all available upgrades: 
  $  ansible all --become --ask-become-pass -i inventory.yml -m apt 
 -a "update_cache=true name='*' state=latest"
