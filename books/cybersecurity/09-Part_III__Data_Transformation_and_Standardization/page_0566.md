This TCP connect scan ( -sT ) command doesn’t resolve DNS names ( -n ); it merely shows open ports and the reason they’re considered so, checking for the top 100 most common ports ( -F ). It uses a speed ( -T4 ) one step faster than default: level 3. Nmap writes the scan results to an XML file ( -oX ),  nmap_results.xml . 
 Use  curl  to POST the  nmap_results.xml  file to Logstash, substituting your own directory paths: 
  $  curl --cacert "/home/j/tls/certs/ca-chain.cert.pem" -H 
 "X-Nmap-Target: 192.168.8.0/24" https://logstash.local:8443 
 --data-binary @/home/j/nmap_results.xml
