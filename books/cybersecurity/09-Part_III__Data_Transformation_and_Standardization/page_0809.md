Delegating Tasks  
 Ansible typically executes tasks on remote hosts specified in the inventory. You may also delegate execution to a specific host if desired and make the action run only once. The following task file snippet would run the task only on your local workstation and only one time: 
  - name: Perform Some Task
  delegate_to: localhost
  run_once: true
 --snip--
