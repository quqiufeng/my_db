Kafka persists all data to disk, and the  /data/kafka  directory will hold that live data, including partitions and replications. In production environments, it should use high-speed, durable solid state or nonvolatile memory express (NVMe) drives. The  /opt/kafka/certs  directory holds TLS files only and doesn’t need any special drives of its own.
