Save and close the administrator text editor. 
 On your Windows host, use WinSCP or another file transfer client to connect over Secure Shell to the Linux host that made the TLS files. Locate Winlogbeat’s public and private keys and signed certificate, then copy them to the  Winlogbeat  folder on Windows. Exit WinSCP once finished. 
 If you don’t have WinSCP, start a Python web server on your Linux host in the directory with the TLS files:
