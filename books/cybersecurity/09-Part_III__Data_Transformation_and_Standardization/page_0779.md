The  copy  module also supports changing file ownership and access permissions, forcibly copying existing files, backing up remote files before being overwritten, and many more options. Here is an example that uses these options: 
  $  ansible all -i inventory.yml -m copy -a "src=records.txt dest=/home/jerry/ 
 owner=jerry group=scta-bni mode=0640 force=true backup=true"
