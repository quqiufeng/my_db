Working with Memcached  
 Now let’s practice working with Memcached. You must use  telnet  to interact with the Memcached program, so operations like using the up arrow to access previous commands aren’t supported. Connect to Memcached on port 11211: 
  $  telnet localhost 11211 
Trying 127.0.0.1...
Connected to localhost.
Escape character is '^]'.
