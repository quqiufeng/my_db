Distributing Public Keys  
 You must distribute SSH public keys to the hosts you want to access. The following command copies the new SSH public key onto the remote server  192.168.2.20  as the remote user  j . Substitute your own IP address and username, or use  localhost  if you’re running a single virtual machine: 
  $  ssh-copy-id -i ~/.ssh/j_id_rsa.pub j@192.168.2.20
