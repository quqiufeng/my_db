Proactive Data Retrieval  
 Many applications and cloud services make data available via application programming interfaces (APIs), which allow you to reach out to the service to retrieve data. APIs may handle weather forecasts, commercial flight departures and arrivals, malware indicators, and millions of other data points. You could even use APIs to request data from the database to which you previously sent the data for analysis.
