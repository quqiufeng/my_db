Dynamic Filenames  
 Templates can create dynamic filenames based on property values like hostnames or IP addresses. The following shows a template that sends firewall messages received from the network to a custom file for each hostname: 
  template(name="hostnamefile" type="string"
string="/var/log/ firewall-%hostname%.log ")
