Interesting possibilities for data enrichment arise when using the  CIDR  and  translate  filters to combine business inventories with cybersecurity data. For example, scripts could query Active Directory for host information and post it to an internal Git instance, which Ansible can then distribute for Logstash to pull from. Similarly, well-structured data that Logstash has enriched can be pulled from the SIEM to automate blocks or generate alerts based on traffic patterns.
