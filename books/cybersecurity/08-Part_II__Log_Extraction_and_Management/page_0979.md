Preventing Drift  
 Because the data nodes don’t check themselves against a leader database, drift may occur if one node is down for maintenance when an indicator push occurs. In this case, you might want to create a custom script to backfill any missed items. You could query your SIEM for the time at which the server was down, then push any indicators found, new or not, into the caches via custom upload to Logstash. This might be a good opportunity for an Ansible task to alleviate missed detection concerns by baking in such backfills to your maintenance playbooks.
