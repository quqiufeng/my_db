TCP and UDP  
 You must load, or import, a module before using it. For example, the following snippet loads the  imptcp , or plaintext TCP, input module and configures port 5514 to receive non-TLS TCP input: 
  module(load="imptcp")
input(
    type="imptcp"
    port="5514"
)
