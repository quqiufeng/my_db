These commands perform the same tasks on Red Hat Enterprise Linux (RHEL), Rocky Linux, and CentOS; take note that on these systems, the service name is  sshd , not just  ssh : 
  $  sudo dnf install openssh-server 
$  sudo firewall-cmd --zone=public --add-service=ssh --permanent 
$  sudo firewall-cmd --reload 
$  sudo systemctl restart sshd
