In most cases, we specify the pipeline ID defined in  pipelines.yml  within the configuration files. This is because the ID acts as a  virtual address  for Logstash to route traffic between pipelines on the same node. In this example, though, we simulated remote Logstash instances communicating by way of hostname and port number. We’ll use pipeline IDs later in this chapter.
