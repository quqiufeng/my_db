Enabling SSH  
 OpenSSH is a collection of tools that implement the SSH protocol to create secure connections, including a tool that allows servers to listen for incoming connections. We’ll use SSH throughout this book, so let’s install OpenSSH now. 
 Run the following commands on Ubuntu to install OpenSSH Server, allow SSH through the firewall, and restart the SSH service: 
  $  sudo apt install openssh-server 
$  sudo ufw allow ssh 
$  sudo systemctl restart ssh
