SAVING CONFIGURATIONS WITH GIT  
  You’ve created many inputs and outputs in this chapter, along with modifications of   pipelines.yml  . In your Git repository, make a new directory for your Logstash configurations and then copy your new files there, and redact any sensitive credentials. Track all changes using   git add .   and then commit them using   git -a -m   &lt;message&gt;  . Finally, use   git push   to send them to your remote repository.
