# OpenCode GUI 布局参考

来源：`/home/quqiufeng/1.png`（OpenCode 1.17.6 主界面截图）

## 整体结构

```
┌─────────────────────────────────────────┬─────────────────────┐
│  消息区（主区域）                        │  右侧信息面板        │
│  - 深色背景                              │  - Session          │
│  - 消息卡片纵向排列                       │  - Context          │
│  - 代码块 / 终端输出块                    │  - LSP              │
│                                          │  - Todo（可折叠）    │
├─────────────────────────────────────────┴─────────────────────┤
│  输入栏                                                        │
├───────────────────────────────────────────────────────────────┤
│  状态栏（模型 · 版本 / tokens / 项目:分支 / OpenCode 版本）     │
└───────────────────────────────────────────────────────────────┘
```

> 注意：截图中虽然有顶部菜单栏（文件 / 动作 / 编辑 / 查看 / 帮助）和 `OpenCode` 标签页，但当前实现**不保留**这些 IDE 元素，因为目标是 coding agent 而非 IDE，且已明确要求去掉顶部标签页。

## 配色（深色主题）

| 区域 | 参考色值 | 说明 |
|------|----------|------|
| 整体背景 | `#1a1a1a` ~ `#1e1e1e` | 统一深色，不要偏蓝/偏青 |
| 消息卡片背景 | `#252526` ~ `#2a2a2b` | 比整体背景稍亮一点，但仍为深色 |
| 消息卡片边框 | 与角色色一致 | 左侧或整体细边框 |
| 代码块背景 | `#1e1e1e` | 深色，接近整体背景 |
| 终端/工具输出背景 | `#0d0d0d` ~ `#151515` | 更黑的终端风格 |
| 右侧信息面板背景 | 与整体背景一致或略深 | 统一深色 |
| 输入栏背景 | `#252526` | 与卡片背景相近 |
| 状态栏背景 | `#1e1e1e` | 深色 |

## 角色颜色

- **User**：偏蓝或青色
- **Assistant**：偏紫或粉色
- **Tool**：黄色/橙色（终端感）
- **Build**：蓝色标签（截图中带蓝色小方块）
- **Todo 未完成**：黄色/橙色
- **Todo 已完成**：灰色或绿色

## 消息卡片样式

1. 卡片有圆角和细边框
2. 顶部标题行：
   - `#1 User` / `#2 Assistant` / `#3 Tool`
   - 字体加粗
   - 工具卡片右侧有 Collapse / Expand 按钮
3. 正文：
   - 普通文本：浅灰/白色
   - ` ``` ` 代码块：提取为独立块，深色背景，顶部显示语言标签
   - 工具输出：终端风格，等宽字体，可折叠

## 右侧信息面板

从上到下：

- **Session**：开始时间、token 数
- **Context**：
  - `179,011 tokens`
  - `68% used`
  - `$0.00 spent`
  - token 使用进度条
- **LSP**：`LSPs are disabled`
- **Todo**：
  - 可折叠列表
  - `[✓]` 已完成 / `[ ]` 未完成
  - 未完成项使用黄色/橙色

## 底部区域

- **输入栏**：多行文本框 + Send 按钮
- **状态栏**：
  - 左侧：`模型 · 版本`
  - 中间：`tokens / tokens (%)`
  - 右侧：`项目:分支`
  - 最右侧：`OpenCode 版本`
